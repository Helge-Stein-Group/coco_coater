# Raw Data

This folder contains the raw experimental data underlying the results
reported in the accompanying paper, *"Low-Cost Doctor Blade Coater with
Integrated Process Characterization"* (CoCo).

**Note:** This data is provided for transparency and reproducibility of
the reported results. It is **not required** to build or operate the
CoCo hardware itself. If you are looking to replicate the coating
platform, please see the main repository README, hardware design files
(CAD/STEP), firmware, and assembly instructions instead.

## Contents

Each subfolder/file corresponds to a specific figure or analysis in the
paper (e.g., substrate topography mapping, uniform/zonal/gradient
coating runs, sensor repeatability characterization, cross-validation
against a handheld micrometer).
